AC6 Mod Controls:

AC experience in Quake 4, faster base default movement speed for the SMG Walker (Mech)

Shift + W for Assault Boost
Shift + A/D for Quick Boost left/right
UPARROW Key to Fly Up
DOWNARROW Key to Fly Down
LEFTARROW/RIGHTARROW Key to Quick Turn

Commands:
spawn vehicle_walker
pm_thirdperson 1 (for 3rd person POV like in AC)

View the weapon loadout GUI menu for the mech automatically when entering the Walker mech, and by pressing Z whenever needed.

LMB shoots Arm weapons
RMB shoots Back weapons
